# Bereft Souls mod list

The mods a Bereft Souls install is expected to run. Only the mods marked
"required by code" are hard dependencies of the pack's own mods; the rest are
the pack's baseline and are installed alongside it.

## Content

| Mod | Notes |
|---|---|
| Calamity Mod | Required by code. Brings Calamity Mod Music with it. |
| Secrets of the Shadows | Required by code. |
| Fargo's Mutant Mod | Required by code. |
| Fargo's Souls Mod | Required by code. Needs Luminance and StructureHelper. |
| Calamity - Fargo's Souls DLC | Required by code (runtime only). Must be a version that loads with Calamity 2.2.2. |

## Bereft Souls

| Mod | Notes |
|---|---|
| QuestBooks | Required by code. The quest book UI. Open it with **L** (rebind under Controls → Mod Controls). |
| Bereft Compatibility | Balance, cross-mod recipes and fixes. |
| The Bereft Souls | Progression and gear guide quest books. |

## Baseline quality of life

| Mod | Notes |
|---|---|
| Magic Storage | Items in storage count toward quest steps (optional integration). |
| Recipe Browser | Shows the pack's changed recipes. |
| Boss Checklist | Calamity and SotS register their bosses. |
| Autostack | |
| Vein Miner | Makes Calamity's large ore veins manageable. |
| [Shared World Map](https://steamcommunity.com/sharedfiles/filedetails/?id=2815010161) | Server-wide map sharing. Last updated July 2024; confirm it loads on the current tModLoader. |

## Considered, not included

- **Unlimited buff slots:** tModLoader already allows 44 buff slots, and
  unlimited stacking of Calamity and Fargo's potions undercuts the boss
  balance. Fargo's Mutant has options for lighter potion upkeep instead.
